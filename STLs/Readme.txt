Full plate.stl is a way to print the RaspiReader enclosure in a single bed on the 3d printer, it is made to a ender 3 neo v2, so a 25x25 bed;
the gcode is set to print with PLA with a big brim to discourage warping;
I had success in printing it with multiple types of PLA, but changes to fit personal use should be made acordingly;
